# `.github`

This repository contains the shared GitHub configuration and organization
profile for [Agent Stacks](https://github.com/agent-stacks).

The [`profile/README.md`](profile/README.md) is displayed on the Agent Stacks
organization profile. Keeping it here gives visitors a concise introduction to
the project and links to its specifications, tooling, packages, and
documentation.

For project work, start with the repositories listed in the organization
profile or visit [agent-stacks.org](https://agent-stacks.org).
