# Agent Stacks

Agent Stacks makes AI-agent tooling easier to compose, reproduce, and
distribute.

A **stack** is an agent client, the plugins and skills it uses, and the
runtimes those components need, built and delivered as one unit. The project
defines conventions for these components and provides tooling to build and
launch them as reproducible packages.

## Explore the project

- **[Agent Stacks Specification](https://github.com/agent-stacks/agent-stacks-spec)** —
  defines how a stack composes Agent Plugins, Agent Skills, and the Model
  Context Protocol, plus what a stack adds on top.
- **[agent-pkgs](https://github.com/agent-stacks/agent-pkgs)** — provides
  reproducible Nix packages for plugins, skills, MCP servers, and their
  runtimes.
- **[agent-stacks.org](https://agent-stacks.org)** — project documentation and
  announcements.

## Get involved

Read the [current specification
draft](https://github.com/agent-stacks/agent-stacks-spec/blob/main/spec/0.1.0.md),
